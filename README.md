🐷 FinFlow

Dashboard financeiro desenvolvido em HTML, CSS e JavaScript durante meus estudos, com controle de receitas e despesas, resumo de gastos por categoria e modo escuro.

Funcionalidades
Cadastro de transações (descrição, valor, categoria e tipo)
Cálculo automático de saldo, receitas e despesas
Resumo dos gastos agrupado por categoria
Histórico de transações com opção de excluir
Dados salvos no navegador com localStorage (não somem ao recarregar a página)
Modo claro/escuro
Tecnologias
HTML5
CSS3
JavaScript (puro, sem frameworks)
Como rodar o projeto
Baixe ou clone este repositório
Abra o arquivo index.html no navegador (ou use a extensão Live Server no VS Code)
Status

Em desenvolvimento — projeto de estudo, próximos passos incluem edição de transações e gráfico de resumo dos gastos.
